## 1. Purpose *(ISO/IEC 27001:2022 Clause 5.3, SOC 2 CC1.3, CC1.4, NIST CSF 2.0 GV.RR-01, GV.RR-02)*
This document defines the key information security roles and responsibilities within [COMPANY_NAME] to ensure the effective implementation and operation of the Information Security Management System (ISMS).

## 2. Executive Management / Board of Directors
- Approving the Information Security Policy.
- Providing adequate resources for the ISMS.
- Participating in Management Reviews.
- Accepting residual risks as defined in the Risk Management Methodology.

## 3. Chief Information Security Officer (CISO) / Security Lead
- Overseeing the daily operations of the ISMS.
- Leading risk assessments and defining risk treatment plans.
- Ensuring compliance with legal, regulatory, and contractual requirements.
- Reporting ISMS performance to Executive Management.
- Managing security incidents and the incident response team.

## 4. IT / Engineering Leadership
- Implementing technical security controls defined by the ISMS (e.g., network security, access controls).
- Maintaining secure configuration of systems and infrastructure.
- Ensuring secure software development lifecycles (SDLC).
- Performing backups and ensuring system availability.

## 5. Human Resources (HR)
- Conducting background checks for new hires *(ISO/IEC 27001:2022 A.6.1, SOC 2 CC1.2, NIST CSF 2.0 PR.AT-01)*.
- Ensuring security responsibilities are included in employment contracts.
- Managing offboarding processes to revoke access promptly.
- Coordinating security awareness training.

## 6. All Employees and Contractors
- Reading, understanding, and adhering to all information security policies.
- Protecting physical and digital assets assigned to them.
- Reporting any suspected security weaknesses, threats, or incidents immediately.
- Completing mandatory security awareness training.
